🚀 Descripción del Proyecto
Este script fue desarrollado para optimizar el cierre contable mensual de una empresa, automatizando la conciliación entre reportes de facturación y servicios devengados. El sistema procesa archivos Excel de gran volumen, identifica periodos de servicio y genera resúmenes financieros automáticos.

🛠️ Problemas Solucionados
✓ Ahorro de Tiempo: Reducción del tiempo de procesamiento manual de horas a segundos.
✓ Detección Automática: El script identifica el mes y año de trabajo basándose en el nombre del archivo más reciente.
✓ Precisión Financiera: Clasificación exacta de montos en PEN y USD, calculando automáticamente provisiones según periodos contables.
✓ Escalabilidad: Capacidad para manejar cientos de registros superando las limitaciones de carga manual en sistemas ERP como Odoo.

💻 Herramientas Utilizadas
Python 3
Openpyxl (Manipulación avanzada de Excel).
Lógica de Periodos: Uso de librerías datetime y calendar para cierres contables precisos.
